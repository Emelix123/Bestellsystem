# Bestellsystem

Bestellsystem für Vereinsfeste: Bestellungen per Handy aufnehmen (Gang → Tisch → Produkte)
und automatisch an die richtige Station (Küche, Getränke, Bier, To-Go) verteilen –
als Bon auf dem passenden Drucker und/oder als Warteschlange auf einem Tablet.

Aktueller Stand: Planung. Siehe [docs/PLAN.md](docs/PLAN.md).
